# iSince

「散髪したのは前回いつだったか」のような、日常の行動・作業について
**前回いつ実施したか**と**前回から何日経過したか**を素早く確認するための記録ツールです。

タスク管理やリマインダーではなく、あくまで**過去の実施記録と経過日数の把握**に特化しています。
次回予定日・期限・通知機能は初版では実装していません。

## 主な機能

- 記録対象（項目）の追加・名称編集・削除
- 実施記録（実施日・簡易メモ）の追加・編集・削除
- 一覧画面でのカード表示
  - 前回からの経過日数を大きく表示
  - 前回実施日・過去の平均的な実施間隔・直近メモを表示
  - カードから直接「今回を記録」できる（詳細画面を開く必要なし）
  - 経過日数がいつもの間隔より長い場合、控えめな参考情報として表示（色だけでなく文字でも表現）
- 詳細画面
  - 前回実施日・経過日数・平均間隔・中央値・最短間隔・最長間隔を表示
  - 履歴を新しい順のタイムライン形式で表示し、記録と記録の間の日数を表示
- 並び替え（経過日数が長い順 / 最近記録した順 / 名前順、初期表示は経過日数が長い順）
- データはブラウザの `localStorage` に自動保存され、再読み込み後も保持されます

## 使い方

`iSince.html` をブラウザで開くだけで利用できます。サーバーやビルド、外部APIは一切不要です。

`main` ブランチへの `iSince.html` の変更は GitHub Actions（`.github/workflows/pages.yml`）により
自動的に GitHub Pages へデプロイされます。ローカルで開く場合はファイルを直接ダブルクリックしても構いません。

1. 「＋ 項目を追加」から記録したい項目（例: 散髪、洗車、歯科検診）を追加
2. 項目カードの「＋ 今回を記録」から実施日とメモを記録
3. カードをクリックすると詳細画面（統計・履歴タイムライン）を確認できます
4. 詳細画面から過去記録の編集・削除、項目名の編集・削除が可能です

## データの保存について

- すべてのデータはブラウザ内の `localStorage`（キー: `isince.data.v1`）に保存されます。
- サーバーへの送信や外部APIとの通信は行いません。
- ブラウザのデータ（サイトデータ／閲覧履歴）を消去すると記録も消えるため注意してください。
- 保存データは将来の仕様変更に備えて `version` フィールドを持っています。

### データ構造（概要）

```json
{
  "version": 1,
  "items": [
    {
      "id": "任意の一意なID",
      "name": "散髪",
      "records": [
        { "id": "任意の一意なID", "date": "2026-08-15", "memo": "夏なので少し短め" }
      ]
    }
  ]
}
```

平均・中央値・最短・最長などの統計値は保存せず、常に `records` の日付から都度計算します。
日付は入力順ではなく日付順に並べ替えて間隔を計算するため、記録の入力順が前後していても正しく計算されます。

## 初版の仕様・制約

- 次回予定日・期限・リマインダー・通知機能はありません
- カテゴリ・タグ機能はありません
- 記録が1件以下など統計値が算出できない場合は、不自然な値を表示せず該当項目を省略します
- 同一日に複数回記録した場合や、日付が前後する記録を入力した場合でも計算・表示が破綻しないように設計しています
- モバイル専用ではなく、PCブラウザでの利用を主眼としたレスポンシブUIです
