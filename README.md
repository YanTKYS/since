# iSince

「散髪したのは前回いつだったか」のような、日常の行動・作業について
**前回いつ実施したか**と**前回から何日経過したか**を素早く確認するための記録ツールです。

タスク管理やリマインダーではなく、あくまで**過去の実施記録と経過日数の把握**に特化しています。
次回予定日・期限・通知機能は実装していません。

## 主な機能

- 記録対象（項目）の追加・名称編集・削除
- 実施記録（実施日・簡易メモ）の追加・編集・削除
- 一覧画面でのカード表示
  - 前回からの経過日数を大きく表示
  - 前回実施日・過去の平均的な実施間隔・直近メモを表示
  - カードから直接「今回を記録」できる（詳細画面を開く必要なし）
  - 経過日数がいつもの間隔より長い場合、控えめな参考情報として表示（色だけでなく文字でも表現）
- 詳細画面
  - 前回実施日・経過日数・平均間隔・中央値・最短間隔・最長間隔を表示
  - 履歴を新しい順のタイムライン形式で表示し、記録と記録の間の日数を表示
- 並び替え（経過日数が長い順 / 最近記録した順 / 名前順、初期表示は経過日数が長い順）
- データはブラウザの `localStorage` に自動保存され、再読み込み後も保持されます
- バックアップ・復元
  - 一覧画面から、全データをJSONファイルとして書き出し（バックアップ）・読み込み（復元）できます
  - `localStorage` だけに依存せず、ブラウザやデバイスをまたいでデータを退避・移行できます

## 使い方

`iSince.html` をブラウザで開くだけで利用できます。サーバーやビルド、外部APIは一切不要です。

`main` ブランチへの `iSince.html` の変更は GitHub Actions（`.github/workflows/pages.yml`）により
自動的に GitHub Pages へデプロイされます。ローカルで開く場合はファイルを直接ダブルクリックしても構いません。

1. 「＋ 項目を追加」から記録したい項目（例: 散髪、洗車、歯科検診）を追加
2. 項目カードの「＋ 今回を記録」から実施日とメモを記録
3. カードをクリックすると詳細画面（統計・履歴タイムライン）を確認できます
4. 詳細画面から過去記録の編集・削除、項目名の編集・削除が可能です
5. 一覧画面の「バックアップ」「復元」から、データの書き出し・読み込みができます（詳細は後述）

## データの保存について

- すべてのデータはブラウザ内の `localStorage`（キー: `isince.data.v1`）に保存されます。
- サーバーへの送信や外部APIとの通信は行いません。
- ブラウザのデータ（サイトデータ／閲覧履歴）を消去すると記録も消えるため注意してください。
- 保存データは将来の仕様変更に備えて `version` フィールドを持っています。

### データ構造（概要）

```json
{
  "version": 1,
  "items": [
    {
      "id": "任意の一意なID",
      "name": "散髪",
      "records": [
        { "id": "任意の一意なID", "date": "2026-08-15", "memo": "夏なので少し短め" }
      ]
    }
  ]
}
```

平均・中央値・最短・最長などの統計値は保存せず、常に `records` の日付から都度計算します。
日付は入力順ではなく日付順に並べ替えて間隔を計算するため、記録の入力順が前後していても正しく計算されます。

## バックアップ・復元

iSince は記録が蓄積するほど価値が高くなるツールです。`localStorage` はブラウザやデバイスに
紐づいた保存先であり、それだけに依存していると、ブラウザのデータ消去や機種変更などで記録を
失うおそれがあります。そのため、`localStorage` とは別に、利用者が任意のタイミングで全データを
JSONファイルとして手元に退避・復元できるようにしています。

### バックアップ

- 一覧画面上部の「バックアップ」ボタンから、現在の全項目・全記録をJSONファイルとしてダウンロードできます。
- ファイル名には出力日が入ります（例: `iSince-backup-20260816.json`）。
- バックアップJSONは、単なる `localStorage` の中身ではなく、iSince のバックアップファイルであると
  判別できる形式（`app` / `backupVersion` / `exportedAt` / `data` を持つ形式）で出力されます。
- 平均・中央値・最短・最長などの計算値はバックアップにも保存されません。復元後は元の記録データから
  都度再計算されます。

```json
{
  "app": "iSince",
  "backupVersion": 1,
  "exportedAt": "2026-08-16T10:56:00+09:00",
  "data": {
    "version": 1,
    "items": []
  }
}
```

### 復元

- 一覧画面上部の「復元」ボタンからJSONファイルを選択できます。
- 選択したファイルは、`localStorage` へ書き込む前にまず内容を検証します。
  iSince のバックアップとして認識できない場合や、対応していない `backupVersion` ・
  `data.version` の場合、必須項目（項目ID・項目名・記録の配列・記録ID・日付など）が
  欠けている場合は、**現在のデータを一切変更せず**、エラーであることが分かるメッセージを表示します。
- 検証に通った場合も即座には上書きせず、「現在のデータが置き換えられること」を明示した確認画面
  （可能な場合は現在の項目数・記録件数を表示）を経てから復元を実行します。
- **復元は、現在のデータをバックアップの内容で完全に置き換える仕様です。** 現在のデータとバックアップの
  内容をマージ（統合）する機能はありません。復元前に今のデータを残しておきたい場合は、先に
  「バックアップ」を実行してファイルを保存してください。
- 復元が完了すると、`localStorage` への保存・画面表示の更新・一覧画面への遷移までを行います。
  ページの再読み込みをしなくても復元後のデータが反映され、再読み込み後も保持されます。

## 現在の仕様・制約

- 次回予定日・期限・リマインダー・通知機能はありません
- カテゴリ・タグ機能はありません
- 記録が1件以下など統計値が算出できない場合は、不自然な値を表示せず該当項目を省略します
- 同一日に複数回記録した場合や、日付が前後する記録を入力した場合でも計算・表示が破綻しないように設計しています
- モバイル専用ではなく、PCブラウザでの利用を主眼としたレスポンシブUIです
- 復元は現在データの完全置き換えのみで、既存データへのマージ・CSV出力は実装していません
